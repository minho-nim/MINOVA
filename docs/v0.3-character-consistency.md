# Crossroads v0.3 — 캐릭터 공식 설정 및 카드 정합성 점검

작성일: 2026-10-28. **보고서·수정안 작성 단계이며 카드·캐릭터 데이터는 변경하지 않았다.** 이번에 확정한 역할을 판단 기준으로 삼되, 기존 인물 관계·성격·비밀·갈등과 의도된 잘못된 정책의 제안은 보존한다. 커밋·푸시·배포를 수행하지 않는다.

후속 상태: 작성 이후 사용자가 C01~C04 실제 수정을 승인했으며 적용을 완료했다. 이 문서의 인용·미적용 표기는 점검 당시 기준으로 보존한다. 현재 적용 상태와 새 검증 결과는 [4개 카드 수정 결과](v0.3-character-consistency-implementation.md)를 참고한다.

## 1. 점검 범위와 결론

현재 등록된 **159개 ID**를 전수 대조했다. 새 수정안은 **4개 카드**, 이번 직책·권한 점검 기준으로 **수정 없이 유지할 카드는 155개**다. 별도로 공통 캐릭터·UI의 직책 표기 통일안을 제시한다. 유지 판정은 모든 윤리 주장이나 수치가 옳다는 인증이 아니라, 이번에 요청한 역할·권한·의료 직무 기준에서 추가 편집할 모순을 확인하지 못했다는 뜻이다.

원본 파일만 읽고 이미 고친 문제를 다시 수정 대상으로 세지 않았다. 실제 경로는 다음과 같다.

- src/data/cards/index.ts: ALL_CARDS / CARD_MAP 등록. ACT I·II·조건부·위기에는 applyCharacterRevision, 일상에는 applyBalanceAdjustment와 applyCharacterRevision을 적용한다.
- src/data/characterRevisions.ts: 기존 v0.3의 발언자·대사 수정 46건. 이번에는 그 적용 결과를 기준으로 검토한다. 예전 한지우 기자·강도현 서장·백시온 변호사 문장이 원본에 남아 있어도 현재 출력과 혼동하지 않는다.
- src/data/cards/act1.ts, act2.ts, conditional.ts, crisis.ts, daily.ts, supervisorReplacement.ts 및 freePlay.ts: 원본 문맥·선택지·분기 조건 확인.
- src/engine/gameEngine.ts: resolveCardDialogue는 문자열 또는 함수형 대사를 현재 플래그·자원으로 해석한다. executeDecision의 선택 주체는 플레이어다. NPC의 제안·요청을 곧바로 NPC의 확정 결정으로 해석하지 않았다.
- src/data/characters.ts, src/data/characterArt.ts: 캐릭터 기본 직책·설명과 시작 화면의 짧은 태그 확인.

159개는 ACT I 25개, ACT II 30개, 조건부 25개, 위기 9개, 일상 45개, 감독관 교체 6개, 자유 운영 선행 정책 19개다. 표의 나열 순서는 등록 배열 기준이며 ACT II의 실제 진행 순서는 storyFlow.ts의 명시적 목록을 유지한다.

### 오혜진의 기준

**30대 초반의 의사이며 NOVA CITY 공공의료 AI 운영 책임자**다. 환자 분류와 AI 권고의 임상적 타당성을 검토하고, 위해를 발견하면 개선·이의제기·인간 의료진의 재평가를 요구한다. 알고리즘 자체를 만드는 개발자가 아니며 비의료 공공서비스 전체를 지휘하지 않는다. 공식 복장은 **청록색 의료 스크럽복과 흰 가운**이다. 기존 의사·전문의·응급 현장 경험은 양립 가능하며 30대 초반이라는 이유만으로 경력을 부정하지 않는다. 병원장 겸직은 확정되지 않았으므로 두 카드의 중앙의료원장 소개는 바로잡을 필요가 있다.

## 8. 기존 테스트·로직·저장에 미치는 영향

이번에는 보고서만 작성했다. 승인 대기 문구를 실행 코드나 카드 수정 레이어에 넣지 않았다. 기존 미커밋 작업을 되돌리거나 정리하지 않는다.

- 카드 ID 159개와 발언자 ID, 조건·repeatable·cooldown·우선순위·가중치·선택지 결과·자원·관계·플래그·지연 효과·예약·명시적 연결은 그대로다.
- ACT I 25장·ACT II 30장의 순서, ACT 완료 화면·자유 운영·위기·감독관 교체를 바꾸지 않는다.
- schemaVersion 5와 저장 키를 유지한다. 브라우저 LocalStorage를 읽거나 쓰지 않았으며 기존 판단 기록·관계·감독관 이력·비밀은 소급 변경하지 않는다.
- 초상화 파일·표정 매핑·UI·색상·공식 복장의 실제 에셋은 변경하지 않았다. 이미지가 생성되면 별도 시각 점검을 수행한다. 새 작화가 이번 단계에서 검수되었다고 보고하지 않는다.
- 문서 작성 전후 src·public·tests·scripts·art의 기존 89개 파일을 SHA-256으로 대조했으며 변경·누락이 없었다.
- 이번 단계에서 게임 자동 테스트·시뮬레이션·실제 UI 플레이는 재실행하지 않았다. 이전 v0.3 보고서의 36개 통과·시뮬레이션 결과는 이전 단계의 결과이며 이번 검수에서 새로 통과했다고 표현하지 않는다.
