# 선택 속도와 설명 읽기 개선

2026-10-30 사용자 플레이 피드백 반영.

- 기존 선택 직후 150ms 잠금만 있던 흐름을, 결과를 저장한 뒤 650ms 동안 선택 확인을 표시하고 다음 카드가 나온 후 450ms 동안 추가 입력을 막는 흐름으로 바꿨다. 스와이프의 기존 220ms 퇴장 애니메이션은 유지한다. 버튼과 스와이프 모두 App의 동일한 잠금을 거친다. 방향키를 누른 채 유지해 생기는 반복 입력도 무시한다. 새 게임과 언마운트 시 남은 타이머를 정리한다.
- 선택 저장은 지연하지 않는다. 진행 순서·일상 카드 삽입·후속 사건 우선순위는 변경하지 않았다. 특히 메인 카드 사이에 다른 사건을 강제로 끼우지 않았다.
- 카드와 함께 움직여 잘리던 승인·거부 스탬프를 제거했다. 카드 상단의 고정 미리보기에서 실제 분기 선택 문장 전체를 보여준다. 긴 설명은 이 영역 안에서 스크롤할 수 있다. 선택 버튼에 마우스를 올려도 같은 설명이 보인다. 스와이프 기준선에 미달한 상태는 계속 밀라는 안내를 구분한다.
- 선택지 전문 버튼은 하단 유틸리티 줄에서 선택 버튼 위쪽의 전체 너비 버튼으로 이동했다. 전체 두 선택을 읽는 기존 모달을 보존한다.
- 대사 전체는 계속 하나의 스크롤 창에 표시한다. 빈 줄 기준 문단을 유지하되 문단 여백을 0.55em로 줄였다.
- 실제 카드에 등장하는 NLP 언어 모델·트리아지·가중치·신경망 등 용어만 본문 하단의 별표 항목으로 제공한다. 펼치면 쉬운 뜻을 읽을 수 있다. 원본 발언·선택 의미·수치·플래그를 바꾸지 않았다.
- 오혜진의 기존 공식 소개는 이미 공공의료 AI 운영 책임자이자 의사로 등록되어 있다. 화면용 공공의료 책임자와 같은 직책임을 용어 설명에 명시했다. 공공서비스 전체를 지휘하거나 AI를 개발하는 인물로 바꾸지 않았다.

## 자원 효과 점검

현재 159개 카드의 318개 선택을 집계했다. 즉시 효과가 2개 자원에 있는 선택 36개, 3개 139개, 4개 143개다. 따라서 175개 선택은 4개 전체가 변하지 않는다. `applyResourceDelta`는 빠진 자원을 0으로 처리한다. 지연된 결과가 동시에 적용되면 판단 기록의 최종 변화는 즉시 효과와 다를 수 있다. 모든 효과를 일괄 조정하지 않았으며, 기존 159개 카드의 자원 값은 유지했다.

## 검증 범위

자동 테스트는 기존 회귀 검증에 용어 설명의 등장 조건, 문단 보존, 실제 자원 누락값 유지, 좌·우 고정 미리보기의 분기 문장 일치 검사를 추가했다. 최종 테스트·타입 검사·빌드 결과는 작업 완료 응답을 기준으로 한다. 현재 브라우저 도구에서 in-app browser를 사용할 수 없어 전환 시간의 체감, 터치 드래그 및 작은 화면의 최종 배치 검증은 미완료다. 실제 모바일 플레이를 검증했다고 보고하지 않는다.
