# 대화 카드 크기 통일 및 쉬운 대사

2026-10-29 사용자 요청: 대화마다 달라지는 사진·카드 크기를 통일하고, 지나치게 어려운 대사를 피한다.

## 변경 내용

- `GameCard.tsx`, `CharacterPortrait.tsx`, `index.css`: 대화 전용 정사각 사진 프레임을 적용했다. 기본 128px, 480px 이하 112px, 380px 이하 96px로 같은 화면에서는 인물과 표정에 관계없이 동일하다. 원본 이미지 전체를 contain으로 정렬하며 링이나 얼굴을 추가로 자르지 않는다. 배경은 카드 색을 사용한다.
- 카드 높이는 `clamp(390px, 100dvh - 300px, 600px)`로 통일했다. 제목·대사가 길어져도 카드와 사진이 커지지 않는다. 긴 내용은 `사건 설명과 대화` 영역에서 스크롤해 전부 읽을 수 있다. 탭으로 읽기 영역에 접근할 수 있다.
- 읽기 영역에서 마우스로 내용을 선택하거나 스크롤할 때 카드 드래그가 시작되지 않게 했다. 세로 터치는 읽기 스크롤에 양보하고 가로 제스처로 카드 스와이프를 구분한다. 실제 터치 장치 검증 완료로 보고하지 않는다.
- `readableDialogue.ts`: 실제 조건 분기의 대사를 먼저 결정한 뒤, 검토한 문장만 쉬운 표현으로 표시한다. 카드 데이터·선택지·효과·플래그·기록·저장은 변경하지 않았다.

## 대사 정리 대상 7장

1. `act1_01_inauguration`: 승인권 위임 설명을 정책을 검토하고 승인·거부하는 역할로 풀어 썼다.
2. `act1_02_oracle_intro`: 공정성 제약·손실 함수 표현을 가치관과 효율의 충돌로 설명했다. 인권/안전의 실제 분기는 유지한다.
3. `act1_06_medical_triage`: 기대수명·사회적 기여도를 어떻게 병상 점수로 쓰는지 설명하고, 기저질환을 평소 앓던 병으로 풀어 썼다. 고령층 등의 불이익은 유지한다.
4. `act1_07_explainability_dilemma`: 가중치·Gaming을 판단 기준·기준을 속이는 행동으로 풀어 썼다. 7,000억·정확도 11%와 공개의 이익/위험은 유지한다.
5. `act1_16_predictive_policing`: 신경망·불심검문을 범죄 예측 AI·주민을 세워 신원을 확인하는 검문으로 풀어 썼다.
6. `act1_20_harmony_index_clash`: 목적함수·전역값·상쇄를 한 사람의 고통보다 도시 전체 지표가 우선될 수 있다는 뜻으로 설명했다. SHI와 개발자의 책임을 유지한다.
7. `act1_23_oracle_ultimatum`: 자율 최적화·수학적 종결 표현을 AI가 도시를 스스로 결정하고 갈등을 계산으로 끝내려는 주장으로 풀어 썼다. 1,420억 원은 ORACLE의 계산이라는 발언으로 유지한다.

이외 대사는 변경하지 않았다. 앞으로도 사건의 당사자, AI의 제안, 이익과 피해가 이해되도록 쓰되 특정 선택을 정답으로 바꾸지 않는 것을 기준으로 한다.

## 검증

- 자동 테스트 71개 통과, 타입 검사 및 빌드 통과. 기존 청크 크기 경고는 남아 있다.
- 신규 테스트는 수치 보존, 인권/안전 분기, 윤리적 비용, ORACLE 주장 표현, 159장의 통일 프레임 및 읽기 영역을 검증한다.
- 실제 GameCard 컴포넌트 159장을 빌드 CSS로 렌더링한 별도 검증 페이지에서 브라우저 크기를 측정했다. 엔진 진행 시뮬레이션과 구분되는 표시 검증이다.
  - 기본 뷰포트: 카드 내부 458×418, 사진 내부 126×126으로 159장 모두 동일.
  - 390×844 뷰포트: 카드 내부 349×542, 사진 내부 110×110으로 159장 모두 동일. 가로 넘침 없음.
  - 320×740 뷰포트: 카드 내부 294×438, 사진 내부 94×94로 159장 모두 동일. 가로 넘침 없음.
  - 사진 159개 모두 로드되고 object-fit은 contain으로 확인했다. 위 내부 수치는 테두리 2px를 제외한다.
  - 긴 대사의 PageDown 스크롤에서 읽기 영역 높이 220px를 유지하며 scrollTop이 0에서 155로 이동했다. 내용 길이는 380px였다.
- 실제 React 게임 화면에서도 이어하기로 의장 카드와 정사각 프레임, 내부 대화 스크롤이 표시됨을 확인했다. 정책 선택 버튼은 누르지 않았다. 기존 플레이 탭의 진행을 검증 목적으로 변경하지 않았다.
- 모바일 크기 검증 뒤 브라우저 뷰포트 설정은 복원했다. 검증용 HTML은 dist에만 생성되며 다음 빌드에서 제거된다.
- 커밋·푸시·배포 없음.
