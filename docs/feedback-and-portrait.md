# 결과 표시 시간과 대화 초상화

- 선택 결과는 표시 후 1.2초에 자동으로 닫습니다. 키보드로 닫기 버튼에 초점을 둔 동안은 읽을 수 있게 유지합니다.
- 다음 선택이 시작되면 직전 팝업을 즉시 닫습니다. 화면 배치와 스크롤에는 영향을 주지 않습니다.
- 인물의 작은 표정 띠를 정사각 대화 프레임으로 확대하던 방식 대신 승인된 큰 기본 초상화를 사용합니다.
  예를 들어 한지우 결의 표정 컷은 237×108, 기본 초상은 360×470입니다.
- 인물의 감정 상태 표시는 유지하지만 대화 초상의 얼굴은 기본 초상입니다. 대체 얼굴을 해당 표정이라고 잘못 설명하지 않도록 접근성 문구도 구분했습니다.
- 표정 갤러리·원본 시트, ORACLE 상태 이미지, 시민·평의회 개별 발언자 초상은 유지합니다.
- 원본 이미지 파일을 수정하거나 AI 업스케일하지 않았습니다.

검증: 자동 검사 82개, TypeScript, 빌드, 3× 배율 모바일의 표시 크기 대비 원본 픽셀 수,
가상 시계로 1.2초 자동 닫힘·다음 선택 시 즉시 닫힘·카드 위치 유지 확인.
