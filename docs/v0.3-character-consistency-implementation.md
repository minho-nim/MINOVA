## 추가 발견 및 범위

- 추가 확인: src/engine/gameEngine.ts의 감독관 교체 기록 생성은 supervisorHistory[].keyVerdict에 원본 choice.text를 저장한다. 감사 접근 카드 선택으로 교체가 동시에 일어날 경우 이 내부 필드에는 종전 영장 문구가 남을 수 있다. 현재 UI에서 이 필드를 직접 출력하는 곳은 확인하지 못했으며, 일반 DecisionRecord.choiceText·consequenceSummary는 새 표현을 사용한다. 원문 선택지·게임 엔진을 보존하고 추가 범위로 넓히지 않기 위해 이번에는 고치지 않았다. 이력 표시 또는 원문 정책을 정리할 때 별도 승인·회귀 검증할 후속 항목이다.
- 기존 초기 번들 크기 경고는 남겼으며 최적화로 범위를 넓히지 않았다.
- 기존 저장의 과거 판단 문구는 이력 보존을 위해 그대로 남고, 이번 이후의 새 판단만 감사 접근 승인·거부 표현을 사용한다.
- 캐릭터 전체의 직책 라벨·이미지 재제작은 이번 4개 카드 수정에 포함하지 않았다. 이미지 생성본이 나오면 별도 공식 설정·표정·확대 품질 점검을 진행한다.
