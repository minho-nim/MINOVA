# 승인 캐릭터 시트 전체 적용

승인: 2026-10-28. 실제 미리보기 재개 및 화면 확인: 2026-10-29.

## 적용 범위

- 첨부 승인본 8종을 `public/assets/approved-20261028/`에 원본 그대로 보존했다. 중복 첨부된 오혜진 2장은 SHA-256이 같아 1종으로 처리했다.
- `characterArt.ts`의 초상화·표정 경로를 승인본 추출 파일로 연결했다. 카드, 시작 화면, 인물 소개와 게임 사이드바가 공통 매핑을 사용한다.
- 시민 6명과 평의회 5명은 집단 초상화로 구성했다. 한 사람을 집단 전체로 대체하지 않는다.
- 시작 화면에 원본 디자인 시트 열기를 추가했다. 전신·표정·의상·소품은 원본 시트에서 볼 수 있다.
- 표시 직책만 공식 명칭으로 연결했다. 기존 캐릭터 ID·대사·관계 및 카드 데이터는 변경하지 않았다.
- 색 보정, 생성형 재작화, 샤프닝, 인위적 확대는 수행하지 않았다. 작은 표정 컷의 실제 세부 해상도는 승인 시트에 포함된 픽셀 수로 제한된다.

## 파일 및 복원

- 적용 스크립트: `scripts/prepare-approved-art.mjs`. 개발용 sharp를 사용하며 게임 의존성이나 외부 API를 추가하지 않는다.
- 원본 해시·추출 좌표: `art/character-sheets/approved-20261028/manifest.json`.
- 적용 전 에셋과 관련 소스 사본: 같은 디렉터리의 `before-application/`. TypeScript 사본은 빌드 대상에 섞이지 않도록 `.bak` 확장자로 보관한다.
- 적용 전 파일 해시: `baseline-sha256.json`. 비교 결과 기존 파일의 변경은 App, CharacterPortrait, GameCard, TitleScreen, characterArt, index.css, v03 테스트에 한정된다. 카드·엔진·저장·캐릭터 원본 데이터 및 기존 에셋은 동일하다.

## 검증 결과와 한계

- 자동 테스트 64개 통과(기존 60개 + 승인 아트 검증 4개).
- 타입 검사 통과. 빌드 통과. 기존 JS 청크 크기 경고는 남아 있다.
- 승인 원본 8종의 SHA-256 일치. 개별 추출 32개의 원본 영역과 출력 픽셀 일치 확인. 집단 타일은 원본 얼굴을 축소·배치한 합성이다.
- 엔진 진단 `valid: true`, 등록 159장, 메인 55장 도달, ACT 완료 화면 절차 및 자유 운영 진입 확인. 단일 진단 경로는 145장을 방문했으며 이를 159장 전체 방문으로 보고하지 않는다.
- 2026-10-29 실제 앱 브라우저에서 시작 화면과 신규 게임 시작 버튼을 통한 첫 선서 카드 화면을 확인했다. 사이드바의 새 인물 이미지, 첫 카드의 평의회 구성원 5인 및 공식 표시 직책을 육안 확인했다.
- 전체 표정의 SSR 및 파일 경로 검증은 통과했으나 모든 인물의 실제 플레이 등장 장면, 모바일 화면, 시트 모달 키보드 조작은 브라우저 회귀 검증 완료로 보고하지 않는다.
- 기존 브라우저 자동 검사 스크립트는 실행 환경의 브라우저/로컬 네트워크 제한으로 완료하지 못했다. 실제 앱 브라우저 확인은 별도로 수행했다.
- 로컬 미리보기: `http://127.0.0.1:4181/`. 커밋·푸시·공개 배포는 수행하지 않았다.
