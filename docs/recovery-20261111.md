# CROSSROADS v0.3 개발 버전 복구

## 원인과 복구 기준

이름 변경 작업은 `cloud-dev`의 `d8a4acc`에서 시작했습니다. 실제 최신 개발 작업은
`codex/v0.3-playtest`의 별도 계보에 남아 있었습니다. 따라서 이후 `main` 배포에는
승인 캐릭터 시트와 v0.3 엔진 개선이 포함되지 않았습니다.

복구 기준은 해당 브랜치의 마지막 커밋 `ed29bbcf067e68de6234fb6b9acd1342b2369903`입니다.
원본 브랜치를 병합해 개발 이력을 연결하고, 복구 이전 `main`은 Git 이력과
`/workspace/recovery/MINOVA-before-recovery.bundle`에 보존했습니다. 강제 푸시는 하지 않습니다.

## 복구한 내용

- 승인된 캐릭터 시트 8종, 개별 초상·표정 이미지, 시민·평의회 이미지와 시트 보기
- 159개 카드, 역할·선택 일관성 보정, 밸런스, 위기·후속 사건 처리
- 순차 스토리 진행, 두 막의 엔딩, 자유 플레이, 저장 데이터 이전·복구
- 시작 안내, 한 개의 대사 스크롤 창, 선택지 전문, 용어 설명, 중복 입력 방지와 좌우 스와이프
- ORACLE 앱 아이콘, 파비콘, 홈 화면 매니페스트

시나리오·엔진·캐릭터·원화·저장 관리 코드는 기준 브랜치 그대로 복구했습니다.
최근의 unslop 스타일 및 대사 변경은 복구 버전에 적용하지 않았습니다.
표시 이름은 MINOVA를 유지하며, 기존 Pages 배포 워크플로를 유지합니다.

## 선택 결과 표시

본문에 공간을 차지하는 패널을 제거했습니다. 별도 포털로 렌더링하는 화면 하단의
고정 팝업은 3.2초 후 사라지며 카드 높이·대사 높이·스크롤을 변경하지 않습니다.
닫기 버튼 외에는 터치와 클릭을 가로채지 않습니다. 실제 변화량을 표시하며
전체 결과는 기존 판단 기록부에 보존됩니다.
