# 모바일 읽기와 시작 목표 안내

작업일: 2026-10-29~30.

## 2026-10-30 사용자 피드백 반영

이전의 대사 쪽수 구분은 사용자가 요청한 읽기 방식과 달라 제거했다. 현재는 원문 전체를 한 창에 표시하고 긴 내용만 그 창 안에서 아래로 스크롤한다. 카드가 바뀌면 본문 스크롤을 맨 위로 되돌린다. 첫 업무 안내의 설명도 같은 방식으로 정정했다. 아래 초기 적용 기록 중 대사 나누기 관련 설명은 현재 동작이 아니다.

주요 인물 소개의 사진 칸은 정사각형으로 맞추고 원본 사진이 칸 전체를 채우게 했다. 모바일 인물 설명과 표정 목록은 사용 가능한 너비 전체를 쓰며, 표정은 동일한 3열로 표시한다. 이미지 원본이나 캐릭터 설정·게임 데이터는 바꾸지 않았다.

변경 후 자동 테스트 74개·타입 검사·빌드 통과. 159개 카드와 분기 대사가 하나의 스크롤 창에 온전히 출력되고 쪽수 UI가 없음을 검사했다. 실제 브라우저 430×850에서 소개 사진 6개의 동일 크기(119×119), 설명·표정 3열 배치와 단일 대사 표시를 확인했다. 320×568에서는 본문 높이 116px / 내용 높이 301px 상태에서 스크롤 위치가 0에서 185px까지 내려가 마지막 문장에 접근 가능했고 바깥 문서 높이는 568px로 유지됐다. 이 확인을 위해 정책을 선택하거나 기존 진행을 초기화하지 않았다.

## 적용 내용

- 새 게임 버튼에서 감독관의 역할, 네 자원, 실제 첫 목표(`act1_obj_inaugurate`)와 조작 방법을 안내한다. 확인 후 기존 새 게임 함수를 실행한다. 안내 취소는 저장을 바꾸지 않으며 이어하기는 안내를 거치지 않는다.
- 시작 소개를 주요 인물 / 시민과 평의회 두 탭으로 나눈다. 키보드 좌우 이동과 선택 상태를 제공한다.
- 게임 높이를 동적 뷰포트에 맞추고 사진·카드·선택 버튼 크기를 화면별로 고정한다. 긴 본문은 이전·다음으로 나누며 작은 화면의 내부 스크롤을 보조 수단으로 유지한다.
- 대사 나누기는 원문과 숫자를 보존하는 표시 처리다. 선택 효과·스토리 진행·저장 구조를 변경하지 않는다.
- 기본 선택 명칭은 두 화면 모두 거부 · 대안 / 승인 · 실행으로 통일한다. 사건별로 작성된 고유 행동 명칭은 유지한다. 선택 버튼에는 세 줄을 표시하고 선택지 전문 창에서 전체 내용을 읽을 수 있다. 창을 읽는 동안 정책 선택 입력을 잠근다.
- 초상화는 원본 파일 그대로 사용해 정사각형을 채운다. ORACLE은 코어 중심으로 표시한다. 전체 디자인은 기존 시트에서 확인할 수 있다. 작은 원화의 실제 해상도를 새로 복원한 작업은 아니다.

## 확인 결과와 한계

- 자동 테스트 74개 통과. 전체 카드의 분기 대사 단어·숫자 보존, 공통 선택 명칭, 소개 탭 검사를 추가했다. 기존 ACT 전환·자유 운영·저장 호환성 회귀 테스트도 포함한다.
- 타입 검사와 프로덕션 빌드 통과. 빌드의 기존 큰 청크 경고는 남아 있다.
- 실제 브라우저에서 390×844 및 320×568 세로 화면의 바깥 크기가 뷰포트와 같고 하단 버튼이 화면 안에 있는 것을 확인했다. 작은 화면에는 본문 내부 스크롤이 남는다.
- 실제 시작 버튼 → 업무 안내 → 첫 목표 확인 → 첫 카드, 소개 탭 변경, 본문 다음 페이지, 선택지 전문 창의 정책 입력 차단, 새 게임 안내 취소 → DAY 1 이어하기를 확인했다.
- 가로 844×390에서 본문 높이가 부족한 것을 발견해 자원·사진·본문을 가로로 재배치했다. 마지막 너비 확장과 ORACLE 채우기 CSS 적용 후 브라우저 연결이 열리지 않아 최종 화면은 재확인하지 못했다. 모든 카드·표정과 모든 휴대폰의 시각 검수를 완료했다는 의미는 아니다.
- 기존 카드 159개, 이미지 파일, 엔진 및 schemaVersion 5 저장 처리에는 변경이 없다. 기존 공개 주소의 사용자 저장을 테스트에 사용하거나 초기화하지 않았다.
