# MINOVA 화면 정리

[unslop](https://github.com/heydamir/unslop), Damir Sokolovsky (@heydamir), CC BY 4.0 지침을 적용했습니다.
원본 스킬과 라이선스는 `.agents/skills/unslop/`에 보관했습니다.

기존 브랜드를 유지하는 정리 작업입니다. 게임 구조, 시나리오, 수치와 저장 키는 유지합니다.

## 방향

- 제품: 도시 정책을 판단하는 한국어 스토리 게임
- 성격: 차분하고 엄격한 감독관 업무 화면
- 배경: 야간 운영국의 전자 문서
- 색을 담을 곳: 기존 인물 원화와 현재 안건
- 고유 요소: 청록색 승인 대기 표시와 선택 표시

## 점검 및 반영

1. 간격: 패널·카드·명단의 간격을 4px 단위로 정리했습니다.
2. 색: 배경 광원과 인터페이스 그라데이션·광택을 제거했습니다. 원화의 색은 유지합니다.
3. 아이콘: Lucide를 유지하고 작은 조작 아이콘의 크기와 두께를 통일했습니다. 장식용 반짝임은 문서 아이콘으로 교체했습니다.
4. 문구: 짧은 제목의 마침표를 줄였습니다. 이미 수정한 초반 대사와 분기는 유지합니다.
5. 글자: 기존 한국어 시스템 글꼴을 유지하고 두꺼운 글씨와 작은 라벨을 정리했습니다.
6. 배치: 기존 섹션 순서와 모바일 카드 조작을 유지했습니다. 카드와 선택 버튼 사이 간격을 정리했습니다.
7. 세부: 성격 태그를 일반 텍스트로, 도시 지표를 숫자 중심으로 정리했습니다. 주의·위기 상태는 문자와 색으로 표시합니다.
8. 이미지: 기존 캐릭터 원화를 유지합니다. 새 이미지 생성이나 영상 제작은 하지 않았습니다.
9. 움직임: 반복 점멸·바운스와 포괄적인 transition-all을 제거했습니다. 선택 피드백과 카드 넘김은 유지합니다.

## 확인

- `npm test`, `npm run lint`, `npm run build`
- 작은 모바일·태블릿·데스크톱 가로 넘침, 인물 선택, 안건 선택, 판단 기록부, 설정, 저장 후 이어하기
- 키보드 초점 표시와 동작 줄이기 설정
