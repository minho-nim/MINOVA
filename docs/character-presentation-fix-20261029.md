# 대화 발언자 및 초상화 표시 개선

2026-10-29. 범위: 대화 화면의 시민·평의회 발언자 식별, 추가 잘림과 ORACLE 검은 띠 수정.

## 변경

- `src/data/cardSpeakers.ts`: 실제 등록된 시민 카드 27장의 내용을 검토해 발언자 역할과 원화 6종 중 사용할 초상을 명시적으로 연결했다. 항만 노동자, 환자 가족 대표, 공공임대 신청자, 이민우 등 실제 사건의 맥락을 사용한다. 여러 사람의 상반된 의견을 전달하는 대사는 의견 전달자로 표시한다. 새 실명·영구 캐릭터 ID·관계 데이터·경력을 추가하지 않는다.
- 평의회 대화는 승인된 고령 의장 초상과 `최고평의회 의장 / NOVA 최고평의회 · 의결사항 전달`을 사용한다. 집단의 의결 내용과 권한을 의장의 개인적 행동으로 재작성하지 않는다.
- `GameCard.tsx`: 해당 카드의 발언자 이름·역할·개별 초상을 표시한다. 시작 화면과 디자인 시트의 시민 6인·평의회 5인 집단 소개는 유지한다.
- `CharacterPortrait.tsx`, `index.css`: 대화 초상은 고정 높이를 없애 원본 가로세로 비율로 렌더링한다. 전체 이미지는 contain으로 표시해 프레임에 맞추느라 얼굴을 자르는 동작을 없앴다. 인물 소개의 상반신도 상단을 기준으로 온전히 표시한다.
- `prepare-approved-art.mjs`: 승인 시트에서 개인 발언자용 초상 11개를 추가 추출한다. ORACLE은 링을 자르는 좁은 세로 영역 대신 링과 본체가 모두 있는 기본 상태 패널(223×180)을 원본 픽셀 그대로 사용한다. 의도적인 색 보정·새 그림 생성·업스케일은 하지 않는다.

## 보존 및 검증

- 적용 직전 사본과 소스 해시: `art/character-sheets/presentation-fix-20261029/`.
- 기존 소스 중 변경은 CharacterPortrait, GameCard, index.css 3개다. cardSpeakers는 신규 표시용 파일이다. 카드·캐릭터 원본·엔진·저장·자원·플래그·기존 ID는 변경하지 않았다.
- 테스트 67개 통과(기존 64개 + 발언자·실제 카드 렌더링·ORACLE 영역 회귀 3개). 테스트는 시민 27장과 모든 평의회 카드의 실제 GameCard 렌더링에서 단일 발언자 초상과 명칭을 검증한다. 집단 소개 유지도 확인한다.
- 타입 검사 및 빌드 통과. 기존 500kB 초과 JS 청크 경고는 남아 있다.
- 실제 앱 브라우저의 DAY 29 저장을 새로고침 후 이어하기로 복원했다. 같은 날짜·자원(88/87/63/77)·ORACLE 최종 제안 카드가 유지됨을 확인했다. 화면에서 링 전체와 검은 세로 띠 제거를 육안 확인했다. 선택 버튼은 누르지 않았다.
- 시민·의장 개별 카드 및 모든 감정의 브라우저 등장 장면을 전부 확인한 것은 아니다. 해당 부분은 SSR 및 파일 검증 결과와 구분한다.
- 작은 표정 컷의 원본 픽셀 수를 넘어서는 고해상도 세부 묘사를 복구한 작업은 아니다. 높은 배율·고밀도 화면에서 더 선명한 표정을 원하면 별도 고해상도 원화가 필요하다.
- 커밋·푸시·배포는 하지 않았다.
